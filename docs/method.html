Method & limits

What is real, what is modelled, and what is made up.

This site is a concept demo. It makes claims about latency, capacity and risk, so every element is labelled. If a number matters to a decision, it needs real data first.

01 · The CoLab method

Think in documents. Review with a human. Then build.

The project follows the Ethical Tech CoLab project startup guide: each document passes a human review gate before the next one starts. This site was built in parallel at the reviewer's request, to make the concept and specification easier to review. It is not the product.

    02 · The truth table

    Four labels, used everywhere.

    Real means it exists and you can check it. Modelled means a deliberate estimate that drives the result. Illustrative means a plausible placeholder that does not change the comparison. Fictional means invented to protect real parties.

    03 · How the simulation works

    One physical world, two ways of running it.

    04 · Scenario catalogue

    Seventeen disruptions, each one a link.

    Each scenario comes from the concept's scenario table. Onset days and detection lags are modelled. Open any of them in the simulation with the same seed and you get the same run.

    05 · How the negotiation room works

    Deals inside a mandate, with a referee.

    The negotiation room adapts the CoLab diplomatic simulator and Diplomacy Table to supplier deals. Our Negotiator desk and a supplier's agent trade across several issues at once. Each side sees only its own channel. A referee flags tactics, checks for a zone of agreement and escalates to a human when the mandate would be breached.
