# Map data

`land-110m.geojson` and `boundaries-110m.geojson` are [Natural Earth](https://www.naturalearthdata.com/)
1:110m land polygons and land boundary lines (public domain), with coordinates rounded to two
decimals to keep the files small. They are drawn on the 3D globe so the simulation needs no
tile server. Boundaries are illustrative and imply no position on any disputed territory.
